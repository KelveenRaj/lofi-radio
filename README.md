# Lo-Fi Radio

A tiny lo-fi player. Click the vinyl to start the stream, click again to pause. While it plays the record glows and bounces along.

It streams [SomaFM's Groove Salad](https://somafm.com/groovesalad/), and there's a light/dark theme toggle in the corner.

## Built with

React 19, Chakra UI, Framer Motion

## Run it locally

```bash
npm install
npm start
```
